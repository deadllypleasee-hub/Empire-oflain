# Подготовка к выпуску

Текущий workflow выдаёт устанавливаемый debug APK для проверки и личного использования. В проект не включены ключи, пароли и токены.

Для Google Play перед выпуском:

1. Завести постоянный release-ключ вне репозитория и настроить безопасную подпись. Не хранить ключ и пароль в Git.
2. Настроить `signingConfig` из внешних переменных/секретов, собрать `./gradlew :app:bundleRelease`.
3. Проверить актуальные требования Play к target SDK; текущая версия использует API 35.
4. Пройти тестирование на физических телефонах, планшетах, Android 8–актуальной версии, с крупным системным шрифтом, отзывом разрешений, нехваткой диска и принудительным завершением процесса.
5. Подготовить страницу приложения, политику конфиденциальности, возрастной рейтинг и Data Safety. В текущей игре нет сетевого разрешения, аналитики и сбора персональных данных.
6. Передать подписанный AAB во внутреннее тестирование и проверить сохранение прогресса при обновлении.

Сохранения находятся в приватном DataStore приложения. Облачная синхронизация, импорт и экспорт не предусмотрены в версии 1.0. Системный backup отключён, чтобы восстановление старого снимка не возвращало уже выданные награды.
