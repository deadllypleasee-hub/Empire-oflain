# EMPIRE · Путь миллиардера

Нативная офлайн-игра для Android: от кофейной стойки и **1 000 ₽** до собственной корпорации. Kotlin, Jetpack Compose, русский интерфейс, портретная ориентация. Никаких покупок за реальные деньги, обязательной регистрации и сторонней рекламы.

## Что можно делать

- Управлять 15 предприятиями: стойка, киоск, кофейня, магазин, автомойка, барбершоп, ресторан, автосервис, супермаркет, фитнес-клуб, автосалон, гостиница, торговый центр, завод, корпорация.
- Расширять каждый бизнес до 8 уровня, улучшать оборудование до 5 ступени, нанимать и увольнять сотрудников, запускать рекламу.
- Открывать бизнесы в четырёх районах и переносить действующие предприятия.
- Получать выручку, оплачивать закупки, аренду, зарплаты, обслуживание и налог 6% с оборота.
- Брать кредиты на 30/90 игровых дней, погашать их автоматически или досрочно.
- Размещать облигации и рискованные инвестиции, переживать события и изменение конкуренции.
- Развивать репутацию, выполнять ежедневные задания, получать 8 достижений, восстанавливаться после банкротства.
- Рассчитывать офлайн-прогресс за первые 8 часов отсутствия; сохранять каждое действие атомарно в DataStore.

Семь рабочих экранов: обзор, бизнесы, город, рынок, банк, профиль и настройки. Профиль открывается через номер уровня справа вверху. Для управления предприятием нажмите на его карточку. Стартовое обучение объясняет экономику.

## Сборка

Требуются **JDK 17**, Android SDK Platform 35 и Build Tools 35.0.0. Минимальная версия телефона — **Android 8.0 (API 26)**.

```bash
# Укажите свой SDK в ANDROID_HOME или в local.properties (не коммитить):
# sdk.dir=/absolute/path/to/android-sdk
chmod +x gradlew
./gradlew :core:test :app:lintDebug :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Это устанавливаемый APK с debug-подписью. Установка:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или перенесите APK на телефон, откройте файл и разрешите установку из выбранного источника. Для обновления поверх установленной игры нужна та же подпись. Автоматический debug-ключ GitHub может меняться между сборками; удаление приложения при несовпадении подписей удалит прогресс.

## APK через GitHub Actions

Workflow [`.github/workflows/android.yml`](.github/workflows/android.yml) запускается при push, pull request и вручную. Он устанавливает Java/SDK, проверяет Gradle Wrapper, выполняет тесты, Android Lint, собирает APK и проверяет подпись.

1. Загрузите проект в свой GitHub-репозиторий.
2. Откройте **Actions → Build EMPIRE APK**.
3. Дождитесь зелёного результата **Test, lint and assemble**.
4. Внизу страницы запуска откройте **Artifacts → EMPIRE-Android-APK**.
5. Распакуйте ZIP и установите `EMPIRE-1.0.0-debug.apk`. Рядом находится `SHA256SUMS.txt`.

Для скачивания Actions Artifacts нужен вход в GitHub. Артефакты хранятся 30 дней. Тестовые и lint-отчёты доступны отдельно в `EMPIRE-Verification-Reports`. Для публичной постоянной раздачи APK можно вручную приложить его к GitHub Release.

## Архитектура

```text
core/      Kotlin/JVM: модели, каталог, экономика, часы, сериализация, тесты
app/       Android: DataStore, ViewModel, Compose UI, WorkManager
.github/   CI-сборка и проверка APK
scripts/   утилиты проверки артефактов
```

Экономика — чистые преобразования состояния; Compose не рассчитывает баланс. ViewModel сериализует изменения через Mutex и публикует их только после успешной записи. Состояние, отметка времени и награды сохраняются в одной транзакции. JSON имеет контрольную сумму и вторую копию той же ревизии. Интернет-разрешение приложению не запрашивается.
